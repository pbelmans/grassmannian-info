Quick reference

Dynkin types classify simple algebraic groups. A parabolic subgroup $P$ is determined by marking a subset of nodes in the Dynkin diagram. The quotient $G/P$ is a partial flag variety.

If a single node $k$ is marked, $G/P$ is a generalised Grassmannian, denoted $X/P_k$. If all nodes are marked, $G/P = G/B$ is the full flag variety.

Invariants computed:

  • Dimension: $\dim G/P = |\Phi^+ \setminus \Phi^+_P|$
  • Index: Fano index $= \gcd$ of anticanonical degrees
  • Euler characteristic: $\chi(G/P) = |W|/|W_P|$
  • Betti numbers: from Poincaré polynomial of $G/P$
  • Anticanonical bundle: $-K_{G/P} = \sum d_i\omega_{k_i}$ where $k_i$ are the marked nodes
  • $\mathrm{h}^0(\omega_{G/P}^\vee)$: sections of the anticanonical bundle (via Borel–Weil)
  • $\mathrm{h}^0(\mathcal{L})$: sections of the ample generator $\mathcal{L} = (\omega_{G/P}^\vee)^{1/i}$
Examples
  • $\mathrm{Gr}(2,5) = A_4/P_2$
  • $\mathrm{OGr}(1,7) = B_3/P_3$
  • $\mathrm{LGr}(3) = C_3/P_3$
  • $\mathrm{OGr}(5,10) = D_5/P_5$
  • Cayley plane $= E_6/P_1$
  • Full flag $A_4/B$
  • $D_5/P_{2,4}$
