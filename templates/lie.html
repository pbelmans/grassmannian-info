Lie.js — interactive Lie theory computations

Lie.js is a JavaScript library for Lie-theoretic computations on partial flag varieties and homogeneous vector bundles. Use the console below to run computations directly in your browser.

>

Click an example to load it into the editor, or to run it immediately in REPL mode.

API reference


All functions from Lie.js are available in the console without import statements. Here is a summary of the main functions.




  
Constructing varieties

  

    

      
FunctionDescription

      
        
Gr(k, n)Grassmannian $\mathrm{Gr}(k,n) = A_{n-1}/P_k$

        
projectiveSpace(n)Projective space $\mathbb{P}^n = A_n/P_1$

        
quadric(n)Smooth quadric hypersurface $Q_n$

        
OGr(k, n)Orthogonal Grassmannian $\mathrm{OGr}(k,n)$

        
SGr(k, n)Symplectic Grassmannian $\mathrm{SGr}(k,n)$, $n$ even

        
LGr(n)Lagrangian Grassmannian $\mathrm{LGr}(n) = C_n/P_n$

        
cayleyPlane()Cayley plane $E_6/P_1$

        
freudenthalVariety()Freudenthal variety $E_7/P_7$

        
partialFlagVariety(dt, marked)General $G/P$: dt is a Dynkin type (string or object), marked is an array of 1-based node indices

        
parseDynkinType(s)Parse a string like "A3", "D5", "E6xA2" into a Dynkin type object

        
adjointVariety(dt)Adjoint variety of the given simple type

        
coadjointVariety(dt)Coadjoint variety of the given simple type

      
    

  






  
Invariants of varieties

  

    

      
FunctionReturnsDescription

      
        
dimension(X)numberDimension of the variety

        
eulerCharacteristic(X)BigIntTopological Euler characteristic (= order of Weyl group quotient)

        
bettiNumbers(X)number[]Betti numbers $\operatorname{b}_0, \operatorname{b}_2, \operatorname{b}_4, \ldots$ (only even-degree ones, which are all nonzero)

        
fanoIndex(X)numberFano index = gcd of anticanonical degrees

        
hilbertSeries(X, d)BigInt[]Hilbert series coefficients $h^0(\mathcal{O}(k))$ for $k=0,\ldots,d$

      
    

  






  
Vector bundles and cohomology

  

    

      
FunctionDescription

      
        
tangentBundle(X)Tangent bundle $\mathrm{T}_X$

        
cotangentBundle(X)Cotangent bundle $\Omega_X$

        
canonicalBundle(X)Canonical bundle $\omega_X$

        
lineBundle(X, weights)Line bundle $\mathcal{O}(\lambda)$ from an array of weights on marked nodes

        
rankBundle(E)Rank of a bundle

        
cohomologyDimensions(E)Array of $h^i(X, E)$ via Borel–Weil–Bott

        
eulerCharacteristicBundle(E)Euler characteristic $\chi(X, E)$

        
directSum(E, F)Direct sum $E \oplus F$

        
tensorProductBundle(E, F)Tensor product $E \otimes F$

        
exteriorPowerBundle(E, k)Exterior power $\bigwedge^k E$

        
symmetricPowerBundle(E, k)Symmetric power $\mathrm{Sym}^k E$

        
dualBundle(E)Dual bundle $E^\vee$

      
    

  






  
Representation theory

  

    

      
FunctionDescription

      
        
dominantCharacter(dt, weight)Dominant character of $\operatorname{V}(\lambda)$ via Freudenthal's formula

        
weylDimension(dt, weight)Dimension of the irreducible representation $\operatorname{V}(\lambda)$

        
tensorProduct(dt, w1, w2)Decompose $\operatorname{V}(\lambda)\otimes \operatorname{V}(\mu)$

        
exteriorPower(dt, weight, k)Decompose $\bigwedge^k \operatorname{V}(\lambda)$

        
symmetricPower(dt, weight, k)Decompose $\mathrm{Sym}^k \operatorname{V}(\lambda)$

        
cartanMatrix(dt)Cartan matrix of the Dynkin type

        
rootSystem(dt)Positive roots of the Dynkin type

        
weylOrder(dt)Order of the Weyl group

        
coxeterNumber(dt)Coxeter number
